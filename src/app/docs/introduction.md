# Introduction

This library lets you write server-rendered Go templates with type safety and full editor support. You can build your views as real Go code, not strings or HTML files. Every component is a function, and you can reuse or compose them like any other Go function. Changes appear instantly while you work, thanks to built-in hot reload.

When it’s time to deploy, everything compiles into a single binary. No runtime dependencies, no extra setup. Rendering is fast by design. Caching is optional if you need it, and streaming is automatic, so large pages start loading right away. The focus is on clear structure, simple tooling, and predictable performance.
